 C. BACKEND & SECURITY
--------------------------------------------------------------------------------
 [C1] NextAuth.js v4 Credentials + Argon2id, 8h JWT in HTTP-only cookies.
      Roles ADMIN/EDITOR baked into JWT (re-login picks up changes).
 [C2] Prisma 6.19.3 + MySQL (16 tables + _prisma_migrations). Additive
      migrations only (admin_panel_setup, add_lead_crm). Singleton client.
      One-time scripts/create-admin.mjs (refuses if admin exists).
 [C3] Server-side authorization on EVERY admin handler (requireAdmin/
      requireEditor); mass assignment impossible (discriminated/strict
      schemas); slug auto-suffixing; publish transitions stamp publishedAt;
      retired URLs revalidated; generic public errors (no stack traces).
 [C4] Lead intake guards — per-IP rate limit, origin allowlist, honeypot +
      time-trap silent success, email-or-phone required, 24h dedup (same
      contact+service reuses lead + NOTE activity).
 [C5] Fail-open notifications — Resend-over-REST (no SDK): inbox alert +
      optional visitor ack; skipped+logged without keys; email failure never
      invalidates a saved lead.
 [C6] Aiven free MySQL: DATABASE_URL uses ?connection_limit=5 and NO
      ssl-mode param (Prisma manages TLS; ssl-mode breaks the handshake).
      .env.production.local staged for Vercel paste (git-ignored).
