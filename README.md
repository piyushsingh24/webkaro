# Digital Agency Website

A premium, modern, and experience-driven digital agency website built with Next.js, React, and Tailwind CSS.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.x or onwards)
- npm (v9.x or onwards)

### Installation
1. Clone the repository (if not already done).
2. Install dependencies:
   ```bash
   npm install
   ```

### 🛠️ Development
Start the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 🏗️ Production
Build the application for production:
```bash
npm run build
```
Start the production server:
```bash
npm run start
```

## ⚙️ Environment Variables
Create a `.env` file in the root directory (or use the existing one) with the following key:
```env
VITE_WEB3FORMS_ACCESS_KEY="your-access-key-here"
```

## 📁 Project Structure
- `src/app`: Next.js App Router pages and layouts.
- `src/components`: Reusable UI components.
- `src/data`: Mock data and configuration.
- `src/assets`: Static assets and images.
